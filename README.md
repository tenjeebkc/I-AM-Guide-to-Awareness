# I AM - A Simple Guide to Awareness

A simple educational website about thoughts, Awareness, and the experience of being present.

The project explores a simple idea:

* A thought can appear without becoming who you are.

It explains how thoughts can be noticed without automatically believing, following, or identifying with them. It also introduces Awareness and I AM in simple, everyday language.

# Features

* Simple explanations about thoughts and Awareness
* Questions and answers for common doubts
* Practical, easy-to-understand examples
* Minimal and responsive design

# Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
